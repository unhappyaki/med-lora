## 本轮针对的问题

1. **术前讨论父子字段重叠**：讨论记录或病历摘要正文内出现姓名、年龄、诊断、手术指征、术式、医师发言时，如果没有独立同级标题，保持在父 Section 内，不拆成子字段。
2. **逐字复制稳定性**：Gold 必须是原文连续子串，保留原文错别字、空格、标点和换行，不做语言润色或格式规范化。
3. **长 JSON 闭合和 Schema 稳定性**：同时覆盖字段较多、slot 较长的样本，降低 JSON 截断、修复和字段丢失。
4. **防遗忘**：术前讨论与首次病程记录按 1:1 rehearsal，避免再次出现 V12 中首次病程增强后术前讨论退化的问题。
5. **清洗约束**：正文不保留 HTML，也不保留模板用 `{}` 符号。

## 仍需单独处理的问题

chunk fallback 重复合并 `年龄`、`记录者` 属于推理代码问题，不应继续用训练样本硬压。建议单独修改 fallback 的跨 chunk 去重/覆盖策略，并用固定回归集验证，避免同时修改数据与推理代码后无法判断收益来源。
